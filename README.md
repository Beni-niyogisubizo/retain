# Retain

A personal expense and monthly budget manager built for my React summative project.

## Technology stack

- Frontend: React, TypeScript, and Vite
- Backend: Node.js and Express (planned)
- Database: MySQL (planned)
- Authentication: React Context (planned)
- Searching, filtering, and sorting: Redux (planned)

## Run the frontend

From the project root:
    cd frontend
    npm install
    npm run dev

## Check the frontend

From the frontend folder:
    npm run build
    npm run lint

## Project status

The frontend scaffold is ready. Application features, backend, and deployment are in progress.
